REHARMONY - website to host online (GitHub Pages, Netlify...)

Upload EVERYTHING in this folder (index.html must be at the top level).
Then open the site's address:
  - Clinician laptop: choose "I am the Maestro" -> you get a 4-digit code + QR code
  - Quest 3 Browser:  choose "I am the Player"  -> type the code -> Enter the concert hall
Both devices only need internet; they do not need to be on the same Wi-Fi.
Messages go through a free public relay (MQTT), so no server or laptop setup is needed.
